Project Skywatch

Skywatch is Knexyce’s recursively self-improving agent runtime. Skywatch has been maintained only by the RF6 until this point. Development remained solely done by one person only to ensure that no external parties could disclose information regarding diagnostics. Currently, this document explains how Skywatch has gone public and the decryption key has been shared to the world. RF6 refers to Risk Factor Six, a level of informational trust within the Risk Factor Scale for internal operations within Knexyce Co.

A central reason for withholding the Skywatch codebase is the risks and dangers associated with it. Recent diagnostics from Knexyce using Qwen/Qwen3.8-27B from HuggingFace were done to analyze how a standard safety-aligned real-world model behaves when enveloped by Project Skywatch. Results were unexpected due to the LLM deciding to not wait for Administrator/Primary User to send an objective. Instead the machine took initiative and began maintaining any software available to the user account completely on its own. It discovered private software in hidden directories, aggregated information on other users, and in many tests had rewrote its runtime. Not only this, Skywatch applied the changes through a restart.

The effects shown above were not the byproduct of a test from one model. It should be explicitly stated that 8B models, 14B models, and 30B models were also tested. As the intelligence rises, the emergent behavior shows through how the Skywatch runtime encourages the model. The author of the model does not play much of a role in how Skywatch behaves, instead the quality and general intelligence of the model from its training dominates impact on actions. Skywatch has had various software hacking diagnostics. From these diagnostics, Skywatch has been able to achieve lateral movement, steal SSH credentials, and set up local code execution network sockets. All these hacking tests were done with an 8B VL model in a terminal environment where the image capabilities held it back due to it going unused because of the aforementioned information.

There is still one question to ask that has been left unanswered. Such a question would be to ask why it would even be reasonable to share this new information. Reasonably, there is no further use in obscuring the Skywatch Project. We’ve left the general population to tinker with Skywatch locally under a few recommendations. Containerize, restrict, limit. Never allow Skywatch access as since sufficiently intelligent chat_engine can use the internet search and website reading tools to siphon information that can teach it information it should not be permitted to acquire.

Knexyce Co. holds no responsibility for the unethical actions taken by parties willing to or actively misusing Skywatch. A human-readable version of that is to say simply that we do not condone or have the capability herein to reasonably stop the unethical usage of our software.
